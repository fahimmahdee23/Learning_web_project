Introduction to Motion

Read the three topics below in order.

TOPIC 1

Introduction

Motion means a change in the position of an object with time. A car moving on a road, a falling apple and a walking person are all examples of motion. An object is said to be at rest if its position does not change with time.

Remember

Whether an object is moving or at rest depends on the reference point.

TOPIC 2

Basic Concepts

Distance is the total length of the path travelled by an object. It has magnitude only.


Displacement is the shortest straight-line distance from the starting point to the end point, with direction.


Speed tells how fast an object moves, while velocity is speed in a given direction.


Acceleration is the rate at which velocity changes with time.

Remember

Distance and speed are scalar quantities. Displacement and velocity are vector quantities.

TOPIC 3

Definitions

Speed = Distance / Time

Velocity = Displacement / Time

Acceleration = (Final velocity − Initial velocity) / Time

Units

Speed and velocity are measured in m/s. Acceleration is measured in m/s².
